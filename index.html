web-revive demos

Give your agent the power to bring dead Flash and Java web games back to life, so they run in any modern browser again. No Flash Player, no Java plugin: these run on Ruffle and CheerpJ.

Get it on GitHub Use it with your agent

Math Slash Flash, ActionScript 2

An arithmetic slashing game made in Flash. Click Play. Revived from the original .swf with no changes.

Original: github.com/andy-shi88/MathSlash · GPL-3.0

Play in your browser

Reversi Java 1.1 applet

Othello against the computer, a Java applet from 2004. Click a square to move. Give it a few seconds to load the Java runtime.

Original: github.com/kwfenske/reversi-game-java · GPL-3.0

Play in your browser

Math Slash runs on Ruffle (open source, bundled here). Reversi runs on CheerpJ, which is proprietary software from Leaning Technologies loaded from their servers. Source code for both games is at the links on each card; verification reports are in the repo under examples/.

Each demo keeps its original license next to it. If web-revive is useful to you, a star on GitHub helps other people find it.
